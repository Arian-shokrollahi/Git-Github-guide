### مراحل پاک کردن (history commit)هایه قبلی و نگه داشتن اخرین (commit) در شاخه جدید که دو مدل یا شاخه پیشفرض مدل دو قرار دادن درون شاخه دیگر و پیشفرض کردن اون شاخه :

## توضیح مختصر درمورد این قسمت

1-شما میاید شاخه (branch)میسازید و فایل ها و فولدر هایه پوشه قبلی رو میریزید توش
2-این شاخه مثل زمانی است که git init میزنید اگر git status بزنید نشون میده که رویه شاخه main
نیستید ولی اون اسمه شاخه ای که با دستور git checkout --orphan branch name میسازید رو نشون نمیده نگران نباشید چون--->بازدن اولین commit بعد git add -A اسم شاخه پدیدار میشه.

<mark style="background: #FF5582A6;">جایه عکسه اینکه نشون نمیده اون شاخه زو</mark>
3-پس شد اول git checkout --orphan branchname سپس میاید git add -A رو میزنید و تمام فایل هازو برایه شاخه جدیدی که با git checkout ساختید به stage میبرید و اگر دستور git status رو بزنید نشون میده که فایل ها در مرحله stage قرار دارند و گیت اون هارو track یا رد یابی کرده.

4-حالا اولین commit رو میزنید و اگر git status بزنید شاخه ای که ساختید رو نشون میده
5-حالا خیالتون راحته که از شاخه اصلی بک اپی در شاخه جدید دارید .
6- حالا با git branch -D oldbranch شاخه قبلی رو پاک میکنید و شاخه جدید رو اسمشو با دستور 
اgit branch -m oldbranchnamd میزارید اسم branch قبلی . چرا چون در مخزن ها شاخه اول default branch است و نمیشه اونو پاک کرد یا باید اسمه شاخه پیش فرضو بکنید شاخه اسم شاخه مد نظرتون یا 
اسم شاخه ای که درست کردید رو با  git branch -m oldbranchname بزارید اسم شاخه قبلی که روش تاریخچه زیادی روش بود تا وقتی git push -f میزنید به مشکل نخورید و گیت فک کنه همون😊بوده ولی تاریخچش پاک شده.
